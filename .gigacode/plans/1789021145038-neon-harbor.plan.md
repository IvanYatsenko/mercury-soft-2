# Mercury-Soft-2 — План реализации (v3.0.0)

## Цель
Создать fullstack приложение (Electron + React + TS + MUI + MobX + Express + SQL.js) для управления конвекционными печами оплавления Меркурий-301/401 с сенсорным экраном 480×320 на Raspberry Pi 4.

## User Directives & Constraints
- Приложение работает на Raspberry Pi 4 с сенсорным экраном 320×480
- Стек: Electron/React/TS/MUI/MobX/SQL/Express
- Монорепо с пакетами: shared (типы), api (Express+SQL.js), client (Electron+React), browser (React+Vite)
- Интерфейс точно по макетам из description/view/panel_480x320/
- Grid layout: 200px left panel + 1fr right panel + 30px scroll bar
- Фиксированный размер 480×320, без отступов и рамок
- ПУСК/СТОП кнопки одинаковой высоты (py: 1.5)
- Одна HomePage с isRunning state вместо двух страниц

## Key Knowledge
- **Структура типов**: Furnace, ThermalProfile, Temperature, Sensor, Heater, OvenSettings, User — в packages/shared/src/interfaces/
- **API Endpoints**: /api/health, /api/thermal-profiles (CRUD), /api/furnace, /api/sensors, /api/heaters, /api/users/me
- **База данных**: SQL.js (вместо better-sqlite3 из-за проблем с нативной компиляцией)
- **Electron**: electron/main.ts загружает http://localhost:5173 при NODE_ENV=development
- **Vite порт**: 5173, **API порт**: 3001, **Browser порт**: 3000
- **Навигация**: внутри страниц через кнопки ←, ПУСК, НАСТРОЙКИ и т.д.
- **HomePage**: isRunning=false показывает режим ожидания (профили, быстрые действия), isRunning=true показывает режим работы (стадия, прогресс, график, таймер)
