# Экранные сообщения Mercury — таблица для редактирования

Дата: 22 октября 2026. Это дополнение к [каталогу причин и действий](error-catalog-2026-10-22.md).

Редактируйте столбец **«Новый текст»**. Столбец **«Сейчас: текст / шаблон»** сохраняет текущую формулировку из кода. Изменения в этом документе пока не меняют приложение.

- `${...}` и `{...}` обозначают подстановки: состояние платы, температуру, время, адрес, описание системной ошибки. Это шаблоны, а не символы, которые целиком видит пользователь.
- Аварийные флаги платы 2, 4, 8, 64, 128 и их комбинации теперь отображаются как «Критическая ошибка» с красным свечением. Технический текст и коды сохраняются сервером в доступном USB-журнале/истории; интерфейс их преобразует при показе. Штатные состояния запуска и выключения к критическим не относятся.
- Один текст может приходить разными путями. При `error.message` показывается сам текст; при `String(error)` или `String(error)` на сервере может добавляться `Error:`. Иногда получается несколько таких префиксов. Ответы ОС/NetworkManager также передаются динамически.
- Подписи индикаторов доступны как подсказка/описание значка, а не постоянно видимый текст. Пометка «на экран не выводится» не является существующей надписью.
- В таблице включены сообщения, которые могут дойти до интерфейса через API, и явно отмеченные сообщения только журнала. Фактический показ каждого сообщения аппаратной аварией не провоцировался.
