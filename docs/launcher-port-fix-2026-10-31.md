# Чёрный экран после смены порта

На 10.10.1.88 сервер отвечал на 8075, но `release/launch.mjs` ожидал `/api/health` на фиксированном 3001. Electron не запускался; через минуту загрузчик завершался с ошибкой и systemd повторял запуск.

В `deploy/legacy/launch.mjs` адрес проверки теперь берётся из `MERCURY_API_PORT`, с 8075 по умолчанию. Аналогично исправлен адрес в `deploy/legacy/install-update.py`: установщик читает порт текущей установки из `.env`.

Оба исправления установлены на 10.10.1.88 с резервными копиями программных файлов. Electron и renderer запущены, на снимке X11 виден главный экран Меркурий-300. Служба остаётся active, NRestarts=0 спустя более двух минут после перезапуска. Процесс профиля idle, нагрев не запускался. Проверка синтаксиса JavaScript и Python прошла. Интерфейс, конфигурация и профили не изменялись.
