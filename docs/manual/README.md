# Руководство пользователя

Готовый документ: [Mercury 3.4.11 PDF](../../output/pdf/Mercury-3.4.11-User-Manual.pdf), 17 страниц, редакция 02.11.2026.

Раздел 1.2 содержит шесть конфигураций: старые М300/М400 только 220 В и новые М301/М401 на 220/380 В. Названия определяются по размерной серии и поколению платы; реальное подключение задаётся отдельно. Раздел 3.10 описывает выбор датчика, нагрев и выдержку калибровки, ввод независимого измерения, условия сохранения и отдельный файл таблиц. Обновлён раздел сохранности данных при установке версии.

Оформление и последовательность разделов основаны на прежнем PDF-руководстве. Содержание заново описывает текущее ПО М300/М400, встроенный экран, ПК и телефон. Технические размеры, схема электропитания и сборка шкафа из старого аппаратного руководства не переносились в программное руководство.

Сборка: `scripts/build-user-manual.py` через комплектный Python с reportlab. Иллюстрации находятся в `assets/`: исходный логотип и снимки установленных интерфейсов 3.3.10. Результат формируется в `output/pdf/`, версия берётся из корневого `package.json`.

Проверка: PDF отрисован Poppler, все 17 страниц просмотрены. Оглавление сверено с нумерацией. Проверены переносы таблиц, рисунки и извлекаемый текст; значение внутреннего PIN в документе отсутствует. Пример графика на странице 7 обозначен как схема, а не результат реального испытания.
