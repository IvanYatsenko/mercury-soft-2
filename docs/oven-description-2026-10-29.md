# Описание в настройках всех интерфейсов

Описание доступно в обычных настройках экрана Raspberry, мобильной и настольной веб-версий. После сохранения оно добавляется к названию через « — ». Пустое описание не добавляет разделитель. Значение хранится в существующем поле `ovenDescription` файла `config.json` и сохраняется после перезапуска.

Обычный PIN разрешает менять только описание; изменение собственного названия по-прежнему требует расширенного доступа. Сервер сохраняет существующее название при запросе только с описанием. Для экрана Raspberry используется общая экранная клавиатура.

Проверены сохранение описания с обычным PIN без смены имени и калибровок, обновление заголовка сразу после сохранения и после перезагрузки страницы на изолированном макете. 30 тестов доступа, обнаружения и веб-интерфейса прошли; сборки сервера, веб-интерфейса и интерфейса Electron успешны.
