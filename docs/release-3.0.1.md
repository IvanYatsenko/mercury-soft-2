# Mercury 3.0.1 — 21 октября 2026

Один универсальный пакет для Raspberry ARM64: М300/М400, подключения
230/380 В. При первом переходе со старого ПО модель и подключение выбираются
в настройках; дальнейшие обновления сохраняют их и профили вне каталога программы.

Включены текущие изменения управления профилем, повторов и поддержания,
обработка двери и аварий, запись истории и технических логов только на USB,
фоновая очистка 80→50%, измеренные характеристики М300/230 В и М400/380 В.
Остальные два подключения требуют отдельных аппаратных измерений.

«Готово» доступна сразу после завершения или остановки, без ожидания 50 °C.
Без поддержания окно закрывается, охлаждение продолжается в фоне. С включённым
поддержанием выполняется переход к 100 °C, после окончания завершающих сигналов.
Профиль, который ещё выполняется, закрыть через «Готово» нельзя.

## Публикация

Файлы находятся в `release/publish`:

- `3.0.1_linux-arm64-unpacked.tar.gz` — 215 220 935 байт;
- `manifest.json` — новый интерфейс обновления;
- `version` — совместимость со старым интерфейсом;
- `SHA256SUMS` — ручная проверка.

Загрузить в прежний каталог обновлений сначала архив, затем манифесты.
SHA-256: `17d163d1ee92e85efdc94930396fac6df26c5cab0ea93c13364a83edb247f9c6`.
Прежний архив 3.0.0 не требуется загружать заново.

## Проверки

Типы, форматирование и сборка прошли. Последний полный серверный прогон:
75/75. После изменения номера версии повторены три теста механизма обновления:
3/3. Готовый архив проверен на ПК: SHA-256 и MD5 совпали с манифестами,
40 файлов программы совпали со сборкой, Node и Electron — ARM64, пути и
ссылки не выходят из пакета, конфигурация/профили конкретной печи не включены.

Во время подготовки этого релиза установка на реальные печи не выполнялась:
пользователь обновит их с сервера и затем сообщит адреса. В dev не отправлено.
