# Мобильная версия — 28 октября 2026

Браузерный интерфейс установлен на обе печи: 10.10.1.88 и 10.10.1.13.
Версия остаётся 3.2.7, коммит и пуш не выполнялись. Обновлён только `pc-dist`;
сервер, `apps/web/dist`, `apps/panel/dist`, настройки и профили не изменены.
Перезапуск сервисов и запуск нагрева не выполнялись.

## Готово

- На ширине до 899 px обычный браузер получает мобильную компоновку общей
  веб-панели; Electron продолжает использовать встроенную компоновку.
- Нижняя навигация: печь, профили, история, ещё. В «Ещё» находятся список печей,
  настройки, переключение темы и инструкция добавления на домашний экран.
- Кнопки запуска, паузы, продолжения/остановки и готовности закреплены над
  навигацией. Перед запуском сохраняется проверка профиля и PIN 3457.
- Профили представлены карточками, редактор расположен в одну колонку.
  В браузере используется клавиатура телефона; в Electron сохранена экранная.
  Несохранённые изменения защищены при переходе через нижнюю навигацию.
- График открывается на полный экран и закрывается отдельной кнопкой.
- Учтены безопасные отступы сверху и снизу для вырезов и системной полоски.
- Иконка PNG 512×512 и favicon взяты из старого mercury-soft-2-PID без изменений.
  Добавлены manifest с display=standalone, apple-touch-icon и метаданные iOS.
  API и команды не кэшируются, service worker и очередь команд не добавлены.

## Как открыть

Телефон должен иметь доступ к сети печи. Открыть
`http://10.10.1.88:3001/` или `http://10.10.1.13:3001/`.

На iPhone: Safari → Поделиться → На экран «Домой», при наличии включить
«Открывать как веб-приложение».
На Android: меню Chrome → Добавить на главный экран. На текущем HTTP это
может быть ярлык браузера, а не полноценная установленная PWA: результат
зависит от браузера. Для полноценной установки Chrome по требованиям браузера,
service worker и фонового push нужен следующий этап с доверенным HTTPS.

IP, записанный в ярлыке, должен оставаться доступным; рекомендуется закрепить
адреса в DHCP. Печь продолжает выполнять профиль независимо от телефона.
После возвращения в приложение команды разрешаются только при свежих данных.

обоих встроенных интерфейсов, сервера, конфигурации и профилей.
