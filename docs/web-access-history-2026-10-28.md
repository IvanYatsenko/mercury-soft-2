# Доступ, главный экран и история — 28 октября 2026

Установлено на М300 (10.10.1.88) и М400 (10.10.1.13), версия остаётся 3.2.7.

- Каждый запуск профиля из веб-версии требует PIN **3457** в окне проверки
  профиля. Открытые настройки не заменяют PIN запуска, код не сохраняется.
  Остановка не требует PIN. На сервере проверяется каждый запрос старта.
- Сеть убрана из бокового меню ПК и открывается кнопкой внутри настроек
  по обычному PIN. Сканирование и изменение сети с удалённого клиента также
  защищены сервером. Общий статус подключения остаётся доступен для индикации.
- История запусков в браузере общедоступна. Встроенное приложение открывает
  историю из настроек после обычного PIN, расширенный PIN не требуется.
  Данные по-прежнему хранятся только на исправной USB-флешке; экспорт журналов
  и новый анализ результатов не добавлены.
- Высота графика на главном экране ПК уменьшена, интервалы и блок оборудования
  уплотнены. При проверке 1280×720 высота области main и scrollHeight равны
  624 px: прокрутки главного экрана нет. Длинные страницы настроек и истории
  продолжают прокручиваться.

Исключение для старта встроенного приложения применяется только к Electron
с loopback-соединением Raspberry. Подмена User-Agent удалённым клиентом
не отменяет проверку PIN. Это существующая модель PIN-доступа локальной сети,
без добавления отдельных учётных записей и арбитража клиентов.

Изменение истории приложения отдельно разрешено пользователем: обновлены
`apps/web/dist` и `pc-dist`, сам Electron runtime `apps/panel/dist` не менялся.
Перезапущен сервис приложения; конфигурация, калибровки и профили сохранены.
Резервные копии на USB: `before-usb-20261028T054201Z` (М300),
`before-usb-20261028T054225Z` (М400), внутри `/media/flash/mercury-logs`.

Проверки: сервер, обе сборки интерфейса и 19 тестов доступа/профилей/обнаружения
прошли; результат `test-results/web-pin-history-2026-10-28.txt`.
В браузере проверены PIN, публичная история и переход к сети из настроек,
в компактной компоновке — кнопка истории и открытие списка.
На обеих Raspberry проверено открытие истории локальным приложением с PIN
3457 (16 и 19 записей соответственно), после проверки доступ закрыт.
Удалённо проверены публичная история, отказ сканирования без доступа,
отказ старта с неверным PIN и поддельным Electron User-Agent:
`test-results/web-access-two-ovens-2026-10-28.json`.
Нагрев во время проверки не запускался.
