# Модели печей и определение платы

Уточнённая нумерация, 02.11.2026:

| Модель | Плата | Подключение |
| --- | --- | --- |
| М300 | Старая | 220 В |
| М400 | Старая | 220 В |
| М301 | Новая | 220 В |
| М301 | Новая | 380 В |
| М401 | Новая | 220 В |
| М401 | Новая | 380 В |

В настройках выбирается размерная серия 300 или 400, а номер отображаемой модели определяется по плате. Размер печи по протоколу не определяется. Произвольное имя и описание пользователя сохраняются; автоматическая модель используется в заголовке при пустом имени и в списке сетевых устройств.

## Что определяется автоматически

Существующий обмен с платой проверяет `describe('@')`. Отсутствие описания соответствует старому протоколу (`220V`); ответ новой платы даёт `230V` или `380V` по прежней схеме протокола. Для нумерации оба новых варианта означают поколение М301/М401. Пока поколение не определено, интерфейс пишет «серия 300/400» без утверждения о конкретной модели.

Это определение протокола и схемы выходов, а не измерение сетевого напряжения. Подключение 220/380 В задаётся по реальной проводке. Для старой платы 380 В запрещены при сохранении и при отправке нагрева из ранее ошибочной конфигурации. Тип платы не переключает автоматически сохранённое питание новой печи.

## Совместимость сохранённых данных

Внутренние `ovenModel: "300"` и `"400"` остаются ключами размерных серий JSON-конфигураций. `connectionVoltage: "230"` остаётся ключом однофазных данных, но показывается как 220 В. Это исключает массовое переименование конфигураций, профилей, моточасов и калибровочных точек.

Четыре уже измеренные характеристики относятся к новым платам и теперь обозначаются М301/220, М301/380, М401/220 и М401/380. Для старой платы они не выбираются: используются исходные характеристики соответствующей серии; их точность требует отдельных испытаний старого оборудования.

Существующие калибровочные ключи `300-230`, `300-380`, `400-230`, `400-380` остаются у новых плат. Для старых плат используются отдельные ключи `300-230-legacy` и `400-230-legacy`, чтобы не применять поправки другого поколения. Моточасы уже разделены по типу платы в ключе счётчиков.

В `/api/device` поле `model` содержит отображаемый номер 300/301/400/401. Каталог печей и перенос профилей принимают все четыре номера; библиотека и регулирование по-прежнему используют совместимые ключи серии. Старый клиент, принимающий только 300/400, нужно обновить для обнаружения М301/М401.

## Проверки

Полный регрессионный прогон: 172 теста, 171 успешно, один Linux-тест пропущен на Windows, ошибок нет. [Результаты](test-results/oven-models-full-2026-11-02.txt). Отдельно проверены шесть допустимых сочетаний, запрет старой платы на 380 В, сохранность конфигурации, выбор характеристик новой платы и раздельные ключи калибровки. Реальное оборудование в ходе этой проверки не нагревалось.
