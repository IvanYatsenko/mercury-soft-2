Установлено на обе печи: М300 (10.10.1.88), М400 (10.10.1.13).
Версия 3.2.7, коммит/пуш не выполнялись. Нагрев для проверки не запускался.
Electron, конфигурация и профили сохранены.

## Работа

Оповещения показываются внутри открытой веб-панели выбранной печи. Работают
по обычному HTTP в локальной сети, без домена, сертификата и интернета.
Это сообщения интерфейса, а не системные фоновые push-уведомления.

События: запуск, завершение цикла, завершение профиля, остановка, ошибка,
потеря связи Raspberry с платой. События подключены к реальным переходам
контроллера профиля и мониторингу платы, а не выводятся из старой истории.

На телефоне: «Ещё» → «Уведомления». На ПК: «Настройки» → «Оповещения открытой
панели». Сообщения включены по умолчанию; завершение каждого цикла можно
включить дополнительно. Настройки событий/звука хранятся только в localStorage
этого браузера для текущего адреса печи. Сами события туда не записываются.

Звук по умолчанию выключен. Нажать «Разрешить и проверить звук» после открытия
панели: браузер разрешает Web Audio только вслед за действием пользователя.
На телефоне фактическая слышимость зависит от громкости, беззвучного режима
и ограничений браузера. Текст сообщения не зависит от доступности звука.

При скрытии вкладки/приложения SSE-соединение закрывается, при возвращении
создаётся заново. Сервер не хранит очередь или историю для повторной выдачи;
Last-Event-ID не используется. Пропущенные в фоне события не воспроизводятся.
От абсолютного времени Raspberry и телефона доставка не зависит.
Когда телефон заблокирован или приложение свёрнуто, доставка не обещается.

На сервере до 32 живых соединений; медленное соединение закрывается вместо
накопления сообщений. Heartbeat 15 секунд. Переоткрытие потока не отправляет
команды управления и не останавливает автономное выполнение профиля.

## Отложенный Web Push

Подготовленный ранее Web Push сохранён в исходниках, но не активирован.
Библиотека загружается только при явной настройке MERCURY_PUBLIC_URL и
MERCURY_PUSH_SUBJECT. Для текущих локальных сообщений она не нужна.
HTTPS и доставка на заблокированный телефон остаются будущим этапом.
