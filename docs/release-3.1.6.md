# Mercury 3.1.6 — 27 октября 2026

- Исправлен доступ к графику текущего запуска: оператору не требуется
  расширенный PIN. Архивная история остаётся доступна только с PIN 34572.
- В правой панели процесса при расширенном доступе показано `Δ max` —
  максимальное абсолютное отклонение от профиля за текущий запуск.
  Значение вычисляется сервером и на экране округляется до целого градуса.
- Пороговые частоты предупреждений вентилятора показаны в Гц от сохранённого
  эталона. Из строки текущей частоты удалён износ.
- Отключено случайное выделение текста интерфейса и перетаскивание изображений;
  редактирование полей ввода сохранено.
- README приведён в соответствие с текущими возможностями и хранением данных.

Установка последних изменений выполнена на 10.10.1.88. Печь 10.10.1.167
не обновлялась после просьбы пользователя не затрагивать выполняющийся процесс.
Смена версии и отправка исходников не публикуют архив на сервер обновлений
и не обновляют печи автоматически.
