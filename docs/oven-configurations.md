# Конфигурации печей

Данные моделей находятся в `packages/shared/ovens/300.json` и `400.json`. Общий
TypeScript-контракт описан в `packages/shared/src/ovens/types.ts`. Номера 300 и
400 соответствуют печам Меркурий-300 и Меркурий-400. Для новой модели
можно добавить `500.json` или `600.json` с теми же полями; после перезапуска
сервера она появится в списке выбора.

При первом запуске пользователь выбирает модель печи и напряжение её подключения
(230 или 380 В). Сервер
записывает их в корневой `config.json`, например:

```json
{
  "ovenModel": "300",
  "connectionVoltage": "230"
}
```

Старые платы на 220 В определяются автоматически при подключении; их не нужно
выбирать вручную. В старой прошивке нет ответа на `describe('@')`, поэтому
сервер использует однофазную схему выходов. Для новых плат ответ `describe('@')`
определяет тип платы по прежней логике протокола. Сохранённое значение старого
поля `boardVersion: "220"` при чтении переводится в `connectionVoltage: "230"`.
Выбор можно позже изменить в «Настройках». `config.json` относится к конкретной установке
и не попадает в Git. Параметры запуска сервера и последовательного порта
остаются в `.env`.

## Источники данных

- Габариты платы, предел температуры, интервал профиля, заявленные скорости и
  мощность: руководство `documents/АМСГ.421415.120РЭ.pdf`, таблица 1.1, стр. 4.
- Индексы восьми выходов `setHV` для однофазной и трёхфазной схемы: старый
  `electron/Entities/Oven/OvenManager.js`, значения `connectors.v300/v400`.
- Поправки термопары и таблицы скорости: старый `electron/Constants/CONST.js`,
  значения `TCORRECT300/400` и `SPEED300/400`.
- Назначение `get[1]`, `get[2]` и `sensors[1]`: старые `PiApi.js`,
  `ApiProxy300.js`, `ApiProxy400.js` и прошивка `docs/firmware-source/source/main.cpp`.

Индексы выходов используются для индикации и проверки элементов в настройках.
Проверка включает один элемент на 3 секунды и затем восстанавливает состояние
выходов до проверки. Работающая конвекция сохраняется; повторная проверка
включённого конвекционного вентилятора недоступна. При инициализации конвекция
включается автоматически. Переключатель в настройках управляет её выходом;
выключение сохраняется до перезапуска сервера и учитывается при повторной
инициализации. Схема выходов выбирается по определённому типу платы
и модели печи. Напряжение подключения печи не ограничивает проверку и сохранено
для будущего распределения нагрузки. Сервер не запускает проверку, если
какой-либо выход, кроме конвекции, уже включён. На реальном оборудовании соответствие выходов нужно подтвердить
отдельно; автоматическое управление нагревом ещё не реализовано.

В руководстве для Меркурий-300 заявлена максимальная скорость нагрева
0,7 °C/с, тогда как в старой таблице `SPEED300.light` есть расчётные значения
до 1,3 °C/с. Оба источника сохранены без исправления: до выяснения причины
расхождения таблицу нельзя считать ограничителем безопасности.
