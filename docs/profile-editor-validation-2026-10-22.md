# Ограничения редактора профиля — 22 октября 2026

По запросу пользователя все вводимые числовые параметры профиля целые:

- температура 0–280 °C;
- начальная точка: время 0 с;
- длительность следующих ручных участков: 1–99999 с;
- выдержки простого режима: 0–99999 с, охлаждение рассчитывается автоматически;
- при включённых повторах: 1–20 циклов; без повторов поле repeat отсутствует.

Редактор показывает неверный или незавершённый ввод без округления и подмены. Поле выделяется красным с пояснением допустимого диапазона; сохранение и преобразование режима заблокированы до исправления. Пустой ввод не превращается в ноль. На экранной клавиатуре числовых полей профиля убраны минус и десятичная точка. Общая клавиатура других настроек сохраняет прежние возможности.

Общая серверная валидация теперь запрещает дробные заданные температуры и больше 20 циклов. Сохранение, изменение и импорт профилей используют эту проверку. Проверено, что неверное изменение/импорт не меняет сохранённые профили. Расчётные промежуточные температуры, исходные измерения и регулятор остаются дробными для точности управления.
